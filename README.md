# hackerrank-solutions
### Key Learnings 
> 1. When using WITH, we use a comma to join multiple CTEs.
> 2. We don't use a comma between GROUP BY and ORDER BY statements
> 3. REPLACE (column_name, '0' , '')is used to remove 0 or any number for example from a string and hence it always returns string(text)
> 4. Therefore, to convert the string back to number we would need to cast it using CAST(... AS SIGNED)
> 5. CEIL is used to round to nearest integer.
